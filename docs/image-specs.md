# 图片规格参考

本文档汇总本站涉及的各类分享图、题图规格及其背景信息，供后续制作和维护图片时参考。

## 1. 本站社交分享图（og-image.jpg）

### 1.1 规格

| 项目 | 规格 |
|---|---|
| 文件 | `static/images/og-image.jpg` |
| 对外 URL | `https://yanlinlin.cn/images/og-image.jpg` |
| 尺寸 | 1200 × 630 px |
| 宽高比 | 1.91:1（1200 ÷ 630 ≈ 1.9048） |
| 格式 | JPEG |
| 设计 | 深色渐变背景（`#1e293b` → `#0f172a`）+ 站点 logo + 站名“不靠谱颜论” + 副标题“颜林林的个人主页” |

### 1.2 为什么是 1200 × 630（历史背景）

- 该尺寸并非任何 ISO/IEC/W3C 标准规定，而是 **Open Graph 协议**（Facebook 2010 年发布的 `ogp.me` 事实标准）在信息流改版中逐渐形成的推荐值，现为各平台引用最多的“公约数”。
- **1200 ≈ 600 × 2**：桌面信息流分享卡片显示宽度约 470–600px，1200px 为其 2 倍，保证 Retina/2x 高密度屏上清晰。
- **高度 = 宽度 ÷ 1.91 ≈ 628**：Facebook 文档取整为 630，Twitter 文档常见写法为 628，两者同源。
- Facebook 未公开 1.91:1 的确切推导过程，它服务于“信息流内不裁切、观感最佳”的卡片比例。

### 1.3 在本项目中的定义位置

| 位置 | 内容 |
|---|---|
| `hugo.yaml` → `params.images.og` | 对外 URL 的唯一配置入口 |
| `scripts/generate-og-image.sh` | 生成脚本（含 `-size 1200x630` 尺寸定义） |
| `package.json` → `scripts.generate:og-image` | `npm run generate:og-image` 一键重新生成 |
| `layouts/partials/meta-social.html` | 渲染为 `og:image` 与 `twitter:image` |
| `layouts/partials/meta-article.html` | 文章页 JSON-LD `Article.image` 的回退值（文章未设 `image` 时使用） |

### 1.4 重新生成

```bash
npm run generate:og-image
```

依赖 ImageMagick（`magick`）与 CJK 字体；字体优先用 `fc-match` 解析 “Noto Sans CJK SC”，可用环境变量 `OG_FONT` 指定。生成过程确定性，同一环境重复生成结果一致。

### 1.5 维护注意事项

- 修改尺寸需同步更新 `scripts/generate-og-image.sh` 中的 `-size` 与 `README.md` 中的描述；`hugo.yaml` 的 URL 不含尺寸信息，无需改动。
- 若更换设计（配色、文案、排版），只需改脚本后重新生成并提交图片文件。

## 2. 微信公众号题图

微信没有公开的协议标准，以下为官方编辑器与运营文档中约定俗成的推荐值。

### 2.1 封面图（题图）

| 项目 | 规格 |
|---|---|
| 推荐尺寸 | 900 × 500 px（比例 9:5） |
| 格式 | JPG / PNG / GIF |
| 大小 | 一般不超过 10MB；GIF 建议更小（约 2MB 以内） |

### 2.2 自动裁剪行为（重点）

微信发布时会从封面图中**自动裁出多种比例**：

- **1:1 正方形小图**：用于订阅号列表缩略图、转发到聊天/朋友圈时的分享卡片；
- **9:5 大图**：信息流头条/大图模式显示。

因此封面主体内容（人脸、标题核心区域）应放在画面中央安全区，四边留白，避免被自动裁切。

### 2.3 正文配图

- 建议宽度 **1080px**（适配主流手机屏幕，微信会自动压缩显示）；
- 高度不限，长图可用；GIF 有体积上限。

### 2.4 与 og 图的区别

| 维度 | 本站 og 图 | 公众号封面 |
|---|---|---|
| 尺寸 | 1200 × 630（1.91:1） | 900 × 500（9:5） |
| 消费方 | Facebook / Twitter 等海外平台 | 微信信息流、转发卡片 |
| 微信行为 | **微信不读取 og:image**，抓取页面正文第一张 `<img>` | 微信自身平台 |

对国内读者而言，文章在微信中的分享效果由**文章首图**决定，而非 og 图。

## 3. 各平台分享图规格速查

| 平台 | 推荐尺寸 | 比例 | 备注 |
|---|---|---|---|
| Open Graph（Facebook） | 1200 × 630 | 1.91:1 | 事实标准，各平台最大公约数 |
| Twitter Card（summary_large_image） | 1200 × 628 | 1.91:1 | 与 Facebook 同源取整 |
| 微信公众号封面 | 900 × 500 | 9:5 | 自动裁剪 1:1 小图 |
| 微信公众号正文 | 宽 1080 | 不限 | 高度不限 |

> 注意：各平台文档随版本改版会调整建议值，制作前建议以各平台最新官方文档为准。

> 本站已于 2026-08 移除全部 `twitter:*` 标签，Twitter 端分享信息通过 `og:*` 标签回退获取（`twitter:image` 缺省时回退 `og:image`，尺寸 1200 × 630 同样符合 Twitter 建议）。
